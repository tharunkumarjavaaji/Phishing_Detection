As a result, this paper suggests the creation of an intelligent phishing detection algorithm that uses the principle of ensemble machine learning algorithms. The method consists of extracting features from URLs in the form of their length, presence of an IP address, use of HTTPS, quantity of subdomains, and domain age. The selected features will then be used for training ensemble models, such as random forests and XGBoost. The use of these models will improve the efficiency of predictions since they involve multiple learning algorithms. Additionally, a web-based application is designed using Flask to facilitate the process of interaction between the users and the system, providing immediate classification of URLs.  Finally, the notification system sends emails to notify the administrator about potential threats The suggested system acts as an automatic phishing detection approach. This solution would help enhance the security of systems while at the same time ensuring that the users remain aware of any possible threats.
